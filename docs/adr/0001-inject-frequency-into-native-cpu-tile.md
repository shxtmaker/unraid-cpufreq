# 将频率注入 Unraid 原生 CPU 磁贴

接受在 Dashboard 页面加载一个无可见磁贴的插件脚本，通过 Unraid 7.3.x 原生 CPU 磁贴的详情 DOM 注入每个逻辑处理器的当前频率和总计行平均频率，而不是修改 `/usr/local/emhttp` 中的系统文件或继续维护独立页面、独立磁贴。处理器频率和平均频率均挂载到对应行的 `span.w26` 标签，不修改原生 `.cpuN` 占用率节点或 `#cpuN` 进度条节点；颜色同步对应原生负载元素的计算颜色。这样既避免频率节点被原生 GraphQL 刷新影响，也能保留系统文件升级安全性；代价是该实现明确依赖 7.3.x CPU 磁贴的 DOM 选择器。
